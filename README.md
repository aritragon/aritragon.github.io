

## Editing the site

- **Research page** (`research.html`): edit the text inside each `<section class="theme">`. To add a paper, copy a `<li class="pub">` block to the top of the Publications list. The paper title links to its PDF (currently the arXiv PDF); to host a PDF yourself, put it in `assets/papers/` and point the title's `href` at it.
- **Talks page** (`talks.html`): copy one of the commented templates at the top of the file (with or without a YouTube video) and fill in the title, venue, description and links. Slides go in `assets/slides/`.
- Shared styling lives in `assets/css/style.css`.
